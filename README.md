# 대한민국 ESG정원정책포럼

Cloudflare Workers + D1 기반 사이트의 독립 복제·인계용 소스입니다. 원본 서비스와 자동 동기화되지 않습니다.

## 포함 내용
- 서버·화면·관리자 JavaScript 모듈 11개
- 참조 이미지·정적 자산 97개
- 페이지 27개, 게시물 4개가 포함된 초기 DB
- 대상 계정 설정 도우미와 새 관리자 인증 설정 스크립트

기존 관리자 비밀번호 해시, 인증 키, 로그인 세션, 문의자 데이터, 접속 통계는 포함하지 않습니다. 원본 Cloudflare 계정이나 DB로 배포하지 못하도록 설정 도우미에 보호 장치가 있습니다.

## 배포
Node.js LTS와 PowerShell 7이 필요합니다. 정적 HTML만 열어서 동작하는 사이트가 아닙니다. 새 Cloudflare 계정의 Worker와 신규 D1 DB에 배포해야 합니다.

상세 절차는 [복제·배포 안내](README_복제안내.md)를 참고하세요. `npm install` 후 대상 계정의 Account ID와 신규 DB UUID를 설정합니다. 관리자 비밀번호는 `setup-secrets.ps1`에서 새로 입력합니다.

## 검증
복제 준비 시 SQL 무결성 검사와 로컬 실행 검사 42개를 통과했습니다. 상대방 Cloudflare 계정 실서버 검증은 배포 후 별도로 수행해야 합니다.

## 권리 및 운영
콘텐츠·사진·서드파티 코드의 권리는 각 권리자에게 있습니다. 공개 저장소라는 사실만으로 별도의 재배포·상업 이용 허가를 부여하지 않습니다. 운영 연락처와 개인정보 안내는 새 운영 주체가 확인·수정해야 합니다.
